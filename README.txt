CAMPUSMART - BCA INTERNSHIP PROJECT

Technology:
- Python
- Django
- SQLite
- HTML/CSS/Bootstrap

SETUP IN VS CODE:
1. Extract the ZIP.
2. Open the CampusMart folder in VS Code.
3. Open Terminal.
4. Create virtual environment:
   python -m venv venv
5. Activate:
   venv\Scripts\activate
6. Install Django:
   pip install -r requirements.txt
7. Run migrations:
   python manage.py migrate
8. Start server:
   python manage.py runserver
9. Open:
   http://127.0.0.1:8000/

The project is intentionally kept medium-level and easy to explain in a BCA viva.
